# Reading the corrected metadata

Historical raw records are retained for auditability. These examples explain why the current metadata and coding tables should be used when citing a source.

| Record or source | Clarification |
|---|---|
| R6_16, arXiv:2405.12016 | The recorded title `Conformalized Strategy-Proof Auctions` is not the verified title. The current v5 is *Statistically Truthful Auctions via Acceptance Rule*; v1 was *Strategy-Proof Auctions through Conformal Prediction*. The record is a preprint. Its statistical guarantee must not be described as exact DSIC. |
| R5_05, Certifying Strategyproof Auction Networks | The raw search title `2 Background` is a PDF section heading. The verified NeurIPS 2020 paper title identifies the source; the historical duplicate decision is unchanged. |
| R5_12, AMENUNet | The raw title was truncated. The complete verified title is *A Scalable Neural Network for DSIC Affine Maximizer Auction Design*. |
| R5_14, Mode Connectivity in Auction Design | Current evidence coding says **locally optimal**, replacing the earlier `near-optimal` wording. The result does not establish global optimality. |
| R3_11, legal rule-based explanations | The full arXiv manuscript is associated with a JURIX 2023 demonstration. A full-length proceedings paper or a causal participant benefit must not be inferred from that demonstration. |
| R2_15, NOM mechanisms | The bounded-rationality reasoning is theoretical; its B-axis relevance tag is not evidence of a participant experiment. |
| R4_06, human evaluation of interpretable models | Human-study evidence concerns predictive model tasks. Transfer to strategic participation needs separate study. |
| R4_14/R4_19 and Nizri's Shapley allocation item | Student abstracts remain explicitly identified as short abstracts. The confirmatory screen did not retain R4_14/R4_19 as a full technical paper. |
| GemNet EC 2024; algorithmic information design EC 2022 | These particular proceedings entries are one-page extended abstracts. The corresponding longer preprints are distinct version records. |
| The Fairness Fair; Recommender Ecosystems; Responsible Mechanism Design | Senior-member agenda/presentation contributions are labeled as such; publication does not make them participant experiments. |
| R1_17, whole-issue table of contents | A real SIGecom issue/contents record, not an individual paper; historically excluded. |
| R5_18, R5_20, R6_04 | Real NeurIPS review webpages, not independent research papers; historically excluded. |
| JEP's Designing Simple Mechanisms; AEA Papers and Proceedings' Quadratic Voting; SIGecom's Automated Mechanism Design survey | Formal publication is verified. Individual conventional peer review was not established, which does not make publication status unknown. |
| Strategyproofness-Exposing Descriptions of Matching Mechanisms | The supplied v4 link and a v3/2025 bibliography description refer to different versions. A version-specific v3 URL is needed when retaining the v3 citation; v4 is a 2026 version. |
| BundleFlow | Official NeurIPS BibTeX supports pages 16853–16876; the DOI-linked proceedings edition gives 19040–19063. Both are recorded as a source/edition discrepancy, not evidence of a fabricated paper. |

Other notes in `verified_sources.csv` record online-versus-issue dates, later formal publications, preprint versions, source access limits and bibliographic details. This table is not an exhaustive change log for capitalization or publisher suffix removal. Historical inclusion decisions are not retroactively changed by the metadata audit.
